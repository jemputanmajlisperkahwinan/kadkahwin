WEBSITE KAD KAHWIN DIGITAL - GITHUB PAGES

Upload semua fail dalam folder ini ke root repository GitHub: index.html, style.css, script.js, music.mp3 dan gambar-pengantin.jpeg.

Pastikan index.html berada terus di root repository, bukan di dalam subfolder. Aktifkan Settings > Pages > Deploy from a branch > main > /(root).

Tema: ceria biru + pink, gambar pasangan di atas nama pengantin, animasi sampul berwarna pastel, kira detik, Google Maps, butang kongsi dan muzik latar.
