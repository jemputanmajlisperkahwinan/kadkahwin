# Website Kad Kahwin Digital

Projek kad kahwin interaktif menggunakan HTML, CSS dan JavaScript biasa.

## Cara uji di komputer
1. Ekstrak fail ZIP.
2. Buka folder `kad_kahwin_digital`.
3. Klik dua kali `index.html` untuk buka dalam Chrome atau Edge.
4. Tekan **Buka Jemputan** untuk melihat animasi dan halaman kad.

## Ciri
- Sampul jemputan dengan animasi buka.
- Tema hijau zamrud dan emas, dengan ornamen tradisional.
- Nama pengantin perempuan dipaparkan di atas nama pengantin lelaki.
- Countdown ke 13 Disember 2026, 11:00 pagi waktu Malaysia.
- Pautan Google Maps.
- Butang kongsi menggunakan fungsi perkongsian telefon/pelayar jika disokong.
- Susun atur responsif untuk telefon dan komputer.
- Kawalan muzik latar.

## Muzik latar
Fail muzik tidak disertakan. Jika Amir mempunyai fail audio yang boleh digunakan, namakan fail itu `music.mp3` dan letakkan dalam folder yang sama dengan `index.html`. Muzik bermula hanya selepas tetamu menekan butang muzik.

## Sebelum diterbitkan
- Semak ejaan nama, tarikh, alamat dan pautan lokasi.
- Untuk butang kongsi menghasilkan pautan awam, hoskan website dahulu.
- Boleh hos secara percuma menggunakan GitHub Pages atau Netlify. Fungsi kongsi dan clipboard mungkin berbeza ketika dibuka sebagai fail tempatan; uji selepas hosting.
- Google Fonts memerlukan sambungan internet; jika tiada internet, pelayar menggunakan fon sandaran.
- Countdown menggunakan waktu Malaysia (UTC+8).


## Kemaskini reka bentuk
- Muzik cuba dimainkan apabila tetamu menekan **Buka Jemputan**. Fail muzik instrumental lembut `music.mp3` disertakan dalam folder. Muzik akan cuba dimainkan apabila tetamu menekan **Buka Jemputan**; pelayar mungkin tetap menyekat audio bergantung pada tetapan peranti.
- Tahun pada panel tarikh dipaparkan sebagai `2026`.
- Font dikemas kini kepada Cinzel, Cormorant Garamond dan Manrope.
- Gerbang kerawang emas ditambah pada skrin pembukaan.
